网络安全学习路径

主线按 pwn.college 官方 dojo 顺序：入门四课 → Intro / Program / System / Software Exploitation 拿 belt。社区 dojo 和中英站点放在对应阶段当配菜，不要打乱 belt 顺序。

01
白带 White belt

第 0 步 · 进门之前

先搞清这是合法的攻防训练，不是去打别人的系统。注册 pwn.college，配好浏览器里的终端 / VS Code，有问题用平台上的 SENSAI。

pwn.college主站 · 从这里领白带Dojos 总目录官方学习顺序就写在这一页
  • OverTheWire Bandit — Linux 命令行热身，不会终端就先打这一关
02
入门 Getting Started

第 1 步 · pwn.college 入门四课（必须按顺序）

后面所有 belt 都默认你会 Linux、二进制怎么跑、程序怎么跟操作系统说话。这四课就是把地基打实，不要跳。

Start Here / Welcome平台怎么用、挑战环境、伦理Linux Luminarium17 模块 · 命令行、权限、管道、进程Computing 10113 模块 · CPU、内存、汇编直觉Playing With Programs程序怎么启动、参数、环境、调试入口
  • Linux Journey — 中英双语 Linux 概念补课
03
黄带 Yellow belt

第 2 步 · Intro to Cybersecurity

官方核心课第一座 belt。从「什么是安全」走到 Web、访问控制、逆向入门。做完才有资格往程序安全走。

  • PicoCTF — 入门 CTF，练搜索、编码、简单逆向
04
橙带 Orange belt

第 3 步 · Program Security

内存、栈、溢出、逆向读懂别人的程序。这是 pwn 的主干，后面 System / Exploitation 都踩在这上面。

Program Security5 模块 · 159 题 · 拿橙带
  • LiveOverflow — 二进制与 CTF 讲解，卡住时对着看
  • Pwntools Tutorials — 社区 dojo：用 Python 写 exploit 脚本
05
绿带 Green belt

第 4 步 · System Security

从「打一个程序」升级到「打一个系统」：权限、隔离、内核与系统调用边界。

System Security6 模块 · 93 题 · 拿绿带
  • Privilege Escalation (community) — 社区提权题很多，System Security 之后再啃
06
蓝带 Blue belt

第 5 步 · Software Exploitation

核心课最后一座。把前面的漏洞知识收成可稳定利用的 exploit。官方会给实体绣带（蓝带起才邮寄）。

Software Exploitation5 模块 · 90 题 · 拿蓝带
  • How2Heap — 堆利用图解，配合 Exploitation 看
07
分支 Electives

官方 belt 走完再选方向。Web、密码、Windows、内核、CTF 题库都是社区 dojo，不再要求按 belt 顺序。

热门梗百科

解释当下还在传的网络梗怎么来的、怎么用，不跟进当事人八卦。词条会对照热搜，正文以百科说明为主。

seed娱乐币圈

孙宇晨 / 磨指甲 / 仅退款文学

Justin Sun / nail-filing / 'refund-only' romance

2026年8月，加密圈人物孙宇晨发布长文《我的女友景甜》，把恋爱、彩礼诉讼和大量生活细节写成一篇「仅退款」式叙事。网友迅速拆出「磨指甲」「喊妈妈」等切片，变成跨平台二创模板。本页只解释梗怎么传播，不评判当事人。

seed音乐抽象

中国人会飞 / 中国人能飞

Chinese people can fly

出自惠州说唱歌手揽佬 2026年7月在美国电台 On The Radar 的 freestyle《中国人能飞》。副歌「中国人能飞，黄皮肤才对」极度洗脑，被配到火箭、战机、游戏高光和日常「上天」画面，还衍生出一套开玩笑的「飞学」。也常被写成「中国人会飞」。

seed表情包动物

背手负鼠

Hands-behind-back opossum

2026年5月，一张背手、眼神放空的北美负鼠抓拍在中文互联网爆红。体态像在工位发呆的社畜，配上「事情终于有了新的退展」一类文案，成为当年的动物顶流表情包。更早的「斗鸡眼负鼠海蒂」也是同类素材。

seed黑话

仅退款文学

Refund-only literature

电商「仅退款」原指退钱不退货。2026年被挪用到情感和公共事件：先深情回忆，再把付出折算成账单，分手就像点「仅退款」。孙宇晨长文是一次集中出圈，但句式本身已经是通用玩法。

seed动物

卡皮巴拉 / 水豚

Capybara

南美最大的啮齿动物，中文互联网里被写成「钝感力」和佛系代言。表情包通常是它泡温泉、发呆或被一堆动物包围，用来表示「我已经不内耗了」。

seed动物

2025年底走红的一类企鹅表情：挺胸、侧目、走路像在参加晚宴。用来嘲「故作优雅」和社交场合硬撑体面，和后来的背手负鼠一样，都是拿动物演人。
